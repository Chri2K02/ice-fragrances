# Brand assets

Source artwork for the Ice Fragrances brand. Versioned here (not under
`public/`) so nothing in this folder is served from the live site; the
production derivatives live in `public/brand/` and `app/icon.*`.

## Inventory

- `FrostEPS.eps` … `IcebergEPS.eps` — Illustrator (v26) product artwork
  sources, DOS-EPS binary format.
- `FrostEPS.svg` … `IcebergEPS.svg` — vector conversions of the above
  (Ghostscript `-dEPSCrop` EPS→PDF, Inkscape PDF→SVG, SVGO).
- `cube (filled).svg`, `drop (filled).svg`, `cube+drop (filled).svg` — the
  brand marks, exported straight from Illustrator.
- `cube (filled+border).svg` — the cube with a white halo border; source of
  the site icon (`app/icon.svg` + PNG/ICO derivatives). The border exists
  because favicons can't be theme-dependent.

Production derivatives: `public/brand/{cube,drop,cube-drop}-{light,dark}.svg`
are the marks with black/white swapped for the dark variants (blues
unchanged), generated by script so both variants share identical geometry.

## Wordmark typeface — planned migration

The wordmark is set in **Glacial Indifference Bold**. That font is ALREADY
self-hosted in the app (`app/fonts/GlacialIndifference-Bold.otf`, loaded via
`next/font/local` in `lib/fonts.ts` as `glacial`), which means the header
logo does not need to stay an image at all:

- Today: `components/Logo.tsx` renders `public/logo-light.png` /
  `public/logo-dark.png` (554×283 rasters) swapped via next-themes, with a
  drop-shadow filter to keep the dark PNG legible — plus a mount-state dance
  to avoid hydration mismatch on the theme.
- Planned: render the mark (`public/brand/` SVG, `currentColor`-able) next
  to real text in `glacial` (Glacial Indifference Bold). Text inherits the
  theme color automatically — no per-theme image swap, no mounted-state
  workaround, no shadow hack, crisper at every size, and lighter than the
  PNGs.

When that migration happens, the PNG logos become redundant; check nothing
else references them (`lib/theme.ts` `logoForTheme`, the JSON-LD
Organization logo, and OG images use logo paths too — the JSON-LD/OG logo
can keep pointing at a raster since schema.org consumers want one).
